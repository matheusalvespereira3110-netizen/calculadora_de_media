# Caculadora de média  #
Este projeto é uma calculadora simples desenvolvida em Python para realizar cálculos de média a partir de números informados pelo usuário.


## Tecnologia Utilizada ##
**python3.14**

## Como Executar ##
**O programa pode ser executado em plataformas online que permitem rodar códigos em Python, como o MyCompiler.** (https://www,mycompiler.io/pt**)

## Exemplo de uso ou demonstracao ##
1. Acesse a plataforma.

2. Selecione Python.

3. Copie o código da calculadora.

4. Cole o código no editor.

5. Execute o programa.

6. Insira os números solicitados.

7. O programa realizará o cálculo da média.

## Exemplo de uso ##
Ao executar o programa, informe os números que deseja utilizar no cálculo.

**Exemplo:**
Digite a primeira nota: 8
Digite a segunda nota: 7
Digite a terceira nota: 9

Média: 8.0
## Objetivo ##
O objetivo deste projeto é praticar conceitos básicos de programação em Python, como:

Entrada de dados;

Variáveis;

Operações matemáticas;

Cálculo de média;

Exibição de resultados.
